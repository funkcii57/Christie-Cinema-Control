Christie Cinema Control is a private Android application for operating a personal cinema system with a Dolby IMS3000 media server and a Christie projector. It shows the current feature, playback status, playlists, sound level, and projector controls.

The app can use The Movie Database (TMDB) to search for a movie poster. A user reviews the suggested poster before saving it locally on their phone. The app does not upload cinema content to TMDB. TMDB access uses a token entered by the user in the app's Service screen.

This is a personal, non-commercial project. The app is not sold or publicly distributed. The project page contains no server credentials, cinema network addresses, or access tokens.
This product uses the TMDB API but is not endorsed or certified by TMDB.
